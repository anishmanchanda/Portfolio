# DockWidgets

[Website](https://anishmanchanda.github.io/DockWidgets-webpage/) · [GitHub](https://github.com/anishmanchanda/DockWidgets)

A native macOS utility that puts transparent widgets in the unused space beside the Dock.

- A flip clock, weather, and media controls for Apple Music and Spotify.
- Custom coordinate geometry computes the Dock's size and orientation across resolutions and Retina displays, using AppKit and CoreGraphics.
- AppleScript automation behind a unified media layer.

**Stack:** Swift, SwiftUI, AppKit, CoreGraphics, AppleScript
