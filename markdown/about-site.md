# About This Site

This portfolio simulates macOS. It's built on [playground-macos](https://github.com/Renovamen/playground-macos) by [Renovamen](https://github.com/Renovamen) (MIT licensed), using [React](https://react.dev/), [Zustand](https://zustand-demo.pmnd.rs/) and [UnoCSS](https://unocss.dev/), and it's self-hosted on my home server.

The source code is [here](https://github.com/anishmanchanda/portfolio). The music in Control Center is an ambient pad generated for this site.
